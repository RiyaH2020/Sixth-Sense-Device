# Sixth Sense Device ✋🏻🎥  

A computer vision project inspired by the **Sixth Sense** concept, enabling gesture-based interaction with digital systems.  
Using a colored object and a webcam, the system supports **air drawing** and **gesture-based image capture**.  

## Features  
- Real-time gesture tracking with **OpenCV**  
- **Air drawing** through object movement mapping  
- **Gesture-triggered image capture**  
- Demonstrates practical applications of **human–computer interaction**  

## Key Insight  
Illustrates how computer vision techniques can translate physical gestures into digital actions.
